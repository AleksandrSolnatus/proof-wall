# QUARK-FINISH-LINE-003 — Atomic payback (frozen before computation)
Date: 2026-10-30. Exploratory sidecar, not canonical Q002.
Question: Does forcing an immediately enabled cancellation after a radius-two seam-neutral crossing guarantee completed rest, and can it improve adversarial worst-case total atomic move cost over hollow seam?
State: n>=3 oriented cyclic tuple x in {0,1,2}^n, seam edge (n-1,0). Conservation, capacity two, sequential execution. Hard legal transfers unchanged.
Hollow actions: each unmarked edge (i,i+1), i=0..n-2: 10->01, 12->21, 02->11, 20->11; marked seam: 02->11,20->11 only. One atomic rewrite costs one move.
Atomic-payback actions: all hollow actions, plus a single indivisible two-rewrite macro if (a) seam has 10 and x[n-2]=2, or (b) seam has 12 and x[n-2]=0. First execute seam-neutral 10->01 or 12->21; immediately execute the newly enabled strict cancellation on edge (n-2,n-1), with no competing action between. Charge TWO atomic moves per macro; control reservation cost recorded separately (at least one local lookahead, edge reservation and commitment). No memory bit or extra move assumed. The macro is an invented *execution-control* policy, not a physically demonstrated implementation. The intermediate state is included in replay; scheduler may select any complete macro or any hollow action. No mid-macro interruption is allowed. Quiescence means no selected actions/macros. Balance = absence of simultaneous zero and two.
For n=3, n-2=1 and the macro edges are distinct; for all n>=3 same definition.
Metrics per state: min/max atomic moves to terminal (including macros cost 2), first balance, balance invariance, any non-goal deadlock, terminal balance, tie choices, potential W, and comparison to hollow. Exhaustive n=3..8 if feasible; independently replay transitions with arithmetic donor/receiver and verify rank descent. No external contact or project modification.
