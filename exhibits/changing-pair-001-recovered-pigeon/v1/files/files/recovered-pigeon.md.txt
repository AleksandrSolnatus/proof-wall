### Mathematical structure the worker described

Eight valid column states (four vertical positions, no adjacent marked cells):

`0000, 0001, 0010, 0100, 0101, 1000, 1001, 1010`

Define `T[u,v] = 1` if `u & v == 0`, and 0 otherwise, with u and v from the eight states. Let `N = 1,000,000,000,039`, `K = 500,000,000,020`, `L=K-1=500,000,000,019`. Then `N = 2K-1`. With `M = T^L` modulo 1,000,000,007,

- `A = sum_v M[1001,v] * M[0101,v]`.
- `B = M[1001,0010] * M[0101,0010]`.
- `C = M[1001,0100] * M[0101,0100]`.

The original worker reported an independent Cayley–Hamilton recurrence check, with characteristic polynomial

`(x+1)(x^2+2x-1)(x^5-4x^4-9x^3+5x^2+4x-1)`.

**Additional discovered invariant:** reverse the order of bits in each 4-bit column. This maps the valid-state graph to itself, fixes `1001`, and swaps `0010` with `0100`. Thus for all nonnegative integer L,

`(T^L)[1001,0010] == (T^L)[1001,0100]`.

The worker concluded that the difference between the B and C totals comes from the second-half contribution, not the first-half path count.
