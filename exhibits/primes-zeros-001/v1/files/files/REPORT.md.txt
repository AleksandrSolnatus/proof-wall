# PRIMES-ZEROS-001 — A small practice exercise

One bounded exercise was completed with a calculation and a separately implemented check. This was not blind discovery or a training update to model weights.

Exact prime counts: π(10)=4, π(100)=25, π(1,000)=168, π(10,000)=1,229. A used an integer sieve; B checked the complete prime list by trial division.

The first positive zero heights supplied are approximately 14.134725142,21.022039639,25.010857580. All ten used heights were copied from Andrew Odlyzko's published table, first ten rows, at https://www-users.cse.umn.edu/~odlyzko/zeta_tables/zeros1 . They specify pairs 1/2 ± it. These are supplied rounded data, not newly computed or independently certified zeros. We performed no rootfinding or zeta residual test.

For the bridge to primes we used ψ(x)=sum(log p for p^k≤x), not π(x). The full explicit formula uses all nontrivial zeros with symmetric truncation; our finite version retains 0,1,5,10 positive-height/conjugate pairs. Its constant and trivial-zero correction stay present even for K=0. Formula source: https://www.math.fsu.edu/~marcolli/bookweb.pdf p 322,equation 2.19. Definitions: https://dlmf.nist.gov/25.10 and https://dlmf.nist.gov/25.16 . The numerical ψ reference uses exact integer prime powers but floating-point logarithms, not exact real arithmetic.

The grid was fixed before calculation:191 half-integers from 10.5 through 200.5, avoiding jump points. It was not selected for a favorable plot. All raw rows/errors are preserved.

Adding zero pairs improved aggregate error on this grid, but not monotonically at each point. In particular, ten versus five pairs worsened 81 of 191 points. There is no certified remainder bound here, no general monotonicity claim, and no proof of the Riemann hypothesis. Do not round this ψ approximation to obtain π.

B checked the whole prime list by trial division, ψ via integer factorization and von Mangoldt values, and each truncated zero sum using an independent real trigonometric expression. All 191 rows and 764 approximations agree within 1e-10; maximum discrepancy 1.4210854715202004e-14. This verifies arithmetic against the supplied table, not the table's completeness or exact zeros. The chart plots ψ(x)−x and the corresponding corrections for 0 and 10 pairs. Black connects reference samples. ψ itself is a staircase; ψ−x slopes downward between jumps. Blue captures some broad fluctuations while missing finer detail. SVG and PNG are saved; final rendering was visually inspected. The original programs used the Python standard library and bounded execution limits. Historical phase timings are not total runtime or a whole-system cost account. No new calculation or checker run was performed for this publication.

Next useful question: how does the number of zeros needed for useful local detail grow as we look farther out? That requires a separately chosen range and error criterion. No further experiment launched.
