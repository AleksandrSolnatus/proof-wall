# Inspect and optionally replay the preserved experiment

The Proof Wall has not executed these programs. The published results are the original October 17, 2026 files; the independent review is historical. Always use a disposable directory for any replay, because the original programs write results.json.

## Recover the logical layout

The site serves inert .txt or .bin copies. The download links retain the original basenames. Restore the files under the following layout; in particular, A/INPUT.json and the top-level INPUT.json are both required and are identical original files.

```
INPUT.json
SOURCES.json
plot.py
A/
  INPUT.json
  calculate_01.py
  results.json
B/
  checker.py
  results.json
  REVIEW.txt
  FINAL-REVIEW.txt
```

To inspect without rerunning, read A/results.json for all 191 rows, four approximations per row, the complete prime list and metrics; B/results.json and the two review files record the separate check. Historical elapsed_seconds fields are phase observations, not performance comparisons.

## Optional execution by a reader

Use Python 3 with its standard library on a POSIX system supporting resource and signal.alarm, such as macOS or Linux. The original source is not directly portable to Windows. Run a normal interpreter, without -O or PYTHONOPTIMIZE: the original checker uses assert for its checks. It is a preserved research checker, not a hardened verifier for arbitrary hostile input.

Copy the layout to a new directory and preserve the downloaded originals elsewhere. From that disposable root:

```
cd A
python3 calculate_01.py
cd ../B
python3 checker.py
```

Each original program sets a 25-second CPU limit and 30-second alarm. The checker reads the top-level INPUT.json and A/results.json and writes B/results.json. Shared rounded inputs and Python math routines remain common dependencies. A replay result would be the reader's new run, not the original receipt.
