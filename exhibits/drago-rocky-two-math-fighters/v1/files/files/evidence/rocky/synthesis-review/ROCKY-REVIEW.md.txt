## Mathematical implication for the particular recognizer

Let F_k be k variable-disjoint copies of Q. A strong backdoor B must touch every copy. Otherwise choose an assignment to B agreeing with a satisfying assignment of F_k. All touched components remain satisfiable, so none can provide an UNSAT shortcut. An untouched copy is exactly Q and still stalls. The current recognizer decomposes components, has no information exchange across independent scopes, and returns LIMITED on that untouched component. Thus this assignment to B is not decided, contrary to the strong-backdoor requirement.

Therefore |B| >= k. Encoded length is O(k log k) with ordinary integer variable labels, so no universal c log_2 N bound holds for this unchanged recognizer. The base gadget's stall is implementation-specific and has been reproduced; the replication argument then covers all k. This does not refute P=NP, a future stronger recognizer, or the packet's conditional 2^b poly(N) theorem. It shows the proposed additional universal logarithmic-backdoor theorem is unavailable for the current recognizer.

Crucially, this family itself is easy for the full solver: component decomposition solves each constant-sized gadget separately. The observed state count for k>=2 is 7k+1. No exponential runtime lower bound follows from the backdoor lower bound. No claim of novelty is made.

## Next useful question

Replace a single global branching-variable budget by recursive decomposition with a bound on total work across the decomposition tree. Independent components combine by conjunction, while a case split creates alternative branches; these have different costs. For independent components costing 2^b_i times polynomial work, sum those costs instead of paying 2^(sum b_i). Prove a global polynomial bound on that sum if possible. This is a useful algorithmic target, not a demonstrated general SAT theorem. Highly connected instances remain unresolved.

The packet's named-family improvements and explicit distinction between certificates and discovery remain useful. Full synthesis audit and universal P/NP claims are beyond these checks.
