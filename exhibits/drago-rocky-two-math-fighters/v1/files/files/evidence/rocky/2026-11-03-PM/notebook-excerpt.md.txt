# Rocky 2026-11-03-PM — condition shared choices, then multiply

Question: extend independent-component factoring to problems with a small shared set S, without combining local solutions that disagree on S.

Established identity / rediscovery: partition original assignments by b in {0,1}^S. Substitute b into ALL original clauses: discard satisfied clauses, remove fixed-false literals, preserve empty clauses. Discover actual connected components in each residual primal graph, including remaining isolated variables. Then #F = SUM_b PRODUCT_components #C_b. A branch with an empty clause contributes zero; zero remaining variables and no false clause contribute one. Each original model has exactly one b and one assignment in every disjoint residual component, so the partition is disjoint and the component extensions form a Cartesian product. This generalizes previous component and conditioning work; not a new theorem or novelty claim.

Counterexample to unconditional multiplication: (not s OR x) AND (s OR not x) AND (not s OR y) AND (s OR not y). The first pair requires s=x and the second s=y. Each pair has two local models, but the conjunction has only two (all false, all true), not 2*2=4. Conditioning on s gives one extension from each component in each of the two branches, totaling two. The code confirms this exactly. The rejected multiplication would pair contradictory values of the same shared variable; no such result is accepted by the implementation.

Additional controls: empty formula on five declared variables still has 32 models after conditioning on two; contradictory units yield zero; a duplicate variable in the conditioning list is rejected to prevent spurious repeated enumeration. Empty S is allowed and remains correct; it just may provide no useful separation.

Limits/costs: enumerating S costs 2^|S| branches. Each discovered component may still require exponential work (this implementation counts it by explicit assignment enumeration). Only if component size is bounded by b does the straightforward per-branch local enumeration cost scale like a sum of 2^b factors, plus substitution and graph overhead; no guarantee makes |S| or b small for arbitrary SAT. Finding a useful separator has its own cost, and this experiment supplies one from its construction instead of solving optimal separator selection. Many generated formulas are easy or inconsistent; no representative-instance or general performance claim. No P=NP/P!=NP conclusion, originality claim, or public literature search.
