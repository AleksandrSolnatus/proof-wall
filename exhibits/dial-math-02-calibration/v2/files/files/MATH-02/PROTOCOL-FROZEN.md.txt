# MATH-02: source-held-out compact-notation pilot
Status: frozen before any calibration model scores. October 17, 2026 Phoenix.

Scope: calibrate the unchanged MATH-01 A–F conditional scorers on short, linear modern mathematical expressions, English words, and registry identifiers. Registry identifiers are a narrow structured nonmath control, not full multi-field records. This pilot cannot satisfy broad calibration of ancient or arbitrary mathematical notation. Source discovery and format inspection precede this freeze; no calibration scores have been inspected. Same-operator execution is not independent blinding.

Sources: five independent mathematical authors: Wentworth (36670), Couturat (10836), Thompson (33283), Whitehead (41568), De Morgan (39041), Project Gutenberg. Five English authors: Carroll (11), Austen (1342), Doyle (1661), Shelley (84), Twain (74). Five IANA registries: ISO country alpha-2, language subtags, HTTP methods, IP protocol keywords, service names. Registry sources share authority and conventions; do not treat these as a random independent population sample.

Selection, before scoring: math first 12 distinct complete inline $...$ expressions after begin{document}, with 3–8 nonspace characters entirely in ASCII letters/digits and +-=<>*/^() apostrophe, containing at least one +-=<>*/^ operator. No macros, braces, truncated expressions, reordering, semantic repairs, or generated examples in empirical controls. Character tokens preserve each printed digit separately. This is an intentionally restricted simple-linear-notation sample, not representative textbook mathematics. Language: first 12 words following the named narrative incipit (record exact anchor in extraction code); case preserved, punctuation removed at word boundaries, letters only; no length cherry-picking. Registry: first 12 distinct identifiers of length 2–8 using letters/digits/hyphen, from the declared identifier field in source order; do not concatenate invented fields. Preserve exact source offsets/row numbers and originals.

Each class pools 5 sources × 12 cells = 60 cells. One bijective character map per class to S01…S45; keep original 45-category Jeffreys prior, concentration 20, and source code byte-for-byte. Do not invent symbols to fill the inventory. A class with >45 observed types is ineligible. Record total tokens, length histogram, observed types, top symbol fraction, collision probability, repeated cell counts against both original Dial branches. Matched-size target: 190–285 tokens (±20% of 237 rounded), 20–45 observed types. Out-of-target but representable classes can be scored as explicitly unmatched diagnostics; never claim matched calibration success from them.

Five folds, each a whole source document/registry. No source appears in both train and test. Build exact/substring/edit-distance≤1 connected components among cells within a class, using original dist1. For a held-out source, purge ALL training cells in any such component touching it. This adapts MATH-01 dependency exclusion without forcing documents with shared short formulae into one unusable fold. Train/test sources remain disjoint; report retained training tokens per fold. Minimum 60 retained training tokens and 2 retained training sources, otherwise fold BLOCKED. Do not alter this floor after seeing results. W is excluded: no comparable physical adjacency. A–F train and tokenprob functions unchanged, original fixed smoothing and conditional prediction task. Exact original observed-score replay precedes calibration (not 399 shuffle reruns).

Primary advantage = min(D,E) loss − min(A,B,C) loss in bits/token; positive math call if >0.05, otherwise no positive call. Report F and min(D,E,F) sensitivity as secondary, not a rescue. Report every source and pooled class. Selection among models is identical in all classes. Success requires all classes profile-matched, all folds evaluable, ≥4/5 math sources positive, ≤1/5 language and ≤1/5 registry sources positive; additionally 95% Wilson lower sensitivity and specificity must both exceed 0.5. With n=5, only unanimous mathematical positives can meet the latter criterion; this intentionally small pilot can readily reject or remain inconclusive, and cannot certify universal performance. Interval independence assumption is approximate, especially registries. No token-level significance or shuffle p-values. Any blocked folds => incomplete calibration, no success; source-specific results remain diagnostics. No tuning, extra sources, or threshold changes after first score.

Implementation controls: deterministic synthetic A/B/C role-separated generators (seed 20261017), 60 cells, original Dial length sequence and 45-symbol inventory; use original dependency components and greedy five-fold assignment. These only test scorer response, not real-math recognition. Record losses, abstain if empty fold. Do not treat winner selection as proof the implementation is correct. Verify bijective relabeling invariance and exact original-score replay.

Resource cap: one extraction, one calibration scoring run, one verification replay; ≤60 seconds CPU for calibration; no paid jobs or outreach. Save raw sources, source URLs/hashes, extraction audit, masked controls, frozen protocol/code hashes before scoring, all results, deviations and final report. Preserve MATH sources and packets 001/002 unchanged.
