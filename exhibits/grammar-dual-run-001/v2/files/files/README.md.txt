# MATH — Two miniature grammar experiments

**Date:** October 15, 2026  
**Status:** Executed locally, machine-checked finite toys.  
**Experimental cases:** 5 original fixed-grammar cases, then a common 31-case comparison plus an independent append-only query-reuse extension.  
**Relation to Terra:** Entirely separate from the staged `MATH-SEVEN-001` work. This does not authorize or report a Terra run.

## Start here

```bash
python3 run_all.py
```

This reruns the five original `GRAMMAR-001` cases, the 31-case `ROOT-GRAMMAR-001` comparison, and its repeat-question extension. It uses Python's standard library, without network, subagents, or external services. The two timing scripts sample process CPU time and **will vary by machine and run**; all logical-status and truth-table assertions must still pass.

Directory structure:
- `fixed-grammar/grammar001.py`: **Experiment 1**. Original fixed grammar: unit propagation only. `baseline-recorded.json` is its saved pre-rerun record; `results.json` is the byte-identical rerun.
- `root-first/root_grammar001.py`: **Experiment 2**. Build named equality/inequality relations from precise CNF clause pairs, compose them, normalize the residual, and apply unit propagation; optionally branch if silent.
- `root-first/benchmark.py`: matched positive-witness verification and repeated CPU diagnostics; includes sham work and enumeration controls.
- `root-first/reuse_extension.py`: build once for an immutable base, then answer 64 appended questions per size at `n=8` and `n=12`, paying the construction once per group; includes mutation invalidation control.
- `root-first/results.json`, `root-first/benchmark.json`, `root-first/reuse-results.json`: raw, auditable per-case evidence and benchmarks.
- `MATH-ROOT-FIRST-GRAMMAR-SEED.md`: preserved original user hypothesis, distinct from the inference rules used here.
- `DUAL-RUN-REPORT.md`: interpretation, scope, and limitations.
- `SHA256SUMS.txt`: hashes of evidence members (excluding itself).

## What “root-first” means operationally

This is a formal analogy to composing words from roots, **not a claim about Hebrew grammar** or the computational complexity of language in general.

1. Shared roots: Boolean variables and truth, negation, disjunction, conjunction.
2. Fixed admissibility rule: two matched binary clauses jointly imply either `a == b` or `a != b`.
3. Instance-conditioned construction: only pairs actually present in a problem contribute a named relationship. Every such pair undergoes a local four-row truth-table proof check.
4. Composition: a parity/disjoint-set structure combines the accepted relationships, detects contradictions, and rewrites surviving clauses into fewer independent variables.
5. Listening: ordinary unit propagation proceeds on this translated structure; **SILENT** is retained whenever the rules are insufficient.
6. Verification: a separate exhaustive all-assignment checker tests translation equivalence for every case (`n <= 8`). Witnesses and UNSAT outcomes are independently checked against an exhaustive solver.

**No rule was generated by looking up the answer**. But the added relational *rule family itself* was hand-designed before executing the test; the experiment does not show automatic discovery of arbitrary mathematical grammars.

## Scientific controls and cost boundaries

- Fixed grammar, search with fixed grammar, root-first grammar, search with root-first grammar, sham construction followed by unchanged fixed search, and first-solution enumeration.
- Cases with true relational motifs versus randomized 3-CNF without them; exact half-pattern negative control, tautology treatment; bijective variable renaming, sign flips, and clause permutations; held-out seeded generated cases.
- All 31 transformations preserve SAT counts and SAT/UNSAT/SILENT status; all 31 compiled translations pass whole-truth-table equivalence checks.
- Build operations, checks for new local relations, original-witness verifications, and append-only reuse are counted. CPU diagnostics include source construction and witness validation, but not the **scientific exhaustive oracle** or human time spent inventing the algorithm. Component counts are not equal-cost machine operations.
- The 12 generated parity test problems share the precise motif targeted by the relational grammar; those are not evidence of general-purpose transfer. The 8 random 3-CNF negative controls show no grammar-only benefit.
- The cached-grammar extension is valid **only for queries appended to the exact same immutable base**. A changed base requires a new compilation; a mutation control shows why.
- No conclusion about `P = NP`, polynomial-time SAT, real-world scaling, or semantic understanding is claimed.
